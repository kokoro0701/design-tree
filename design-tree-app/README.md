# プログラム設計ツリー（独立アプリ版）セットアップ手順

iPhone・Android・PC で使える「ホーム画面アプリ」です。
ログインすると、スマホと PC で同じプロジェクトを使えます（同期）。Claude のアカウントは要りません。

使うもの（どちらも無料）:

- **Firebase**（Google のサービス）… ログインとデータの保存
- **GitHub Pages** … アプリを公開する場所

かかる時間は 20〜30 分くらいです。Firebase の画面の表示名は、時期によって少し違うことがあります。

---

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `firebase-config.js` | **あなたの Firebase の設定を貼るファイル**（手順 3） |
| `firebase-sync.js` | ログインと同期の処理 |
| `firestore.rules` | データを本人しか読み書きできないようにする設定（手順 4） |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面アプリ・オフライン用 |

`firebase-config.js` が空（`null`）のままでも、アプリは「この端末だけに保存」で使えます。

---

## 1. Firebase のプロジェクトを作る

1. PC で <https://console.firebase.google.com/> を開き、Google アカウントでログインします。
2. 「プロジェクトを作成」（または「プロジェクトを追加」）を押します。
3. 名前を入れます（例: `design-tree`）。
4. Google アナリティクスは「オフ」で大丈夫です。
5. 「プロジェクトを作成」を押し、終わるまで待ちます。

## 2. メールアドレスでのログインを使えるようにする

1. 左のメニューで「構築」→「Authentication」→「始める」を押します。
2. 「ログイン方法」タブで「メール / パスワード」を選びます。
3. 一番上の「有効にする」をオンにして「保存」します（下の「メールリンク」はオフのままで大丈夫です）。

## 3. アプリを Firebase に登録して、設定をコピーする

1. 左上の「プロジェクトの概要」の横の歯車 →「プロジェクトの設定」を開きます。
2. 下の方の「マイアプリ」で、ウェブのアイコン `</>` を押します。
3. ニックネームを入れて（例: `design-tree-web`）「アプリを登録」を押します。
   「Firebase Hosting も設定する」のチェックは不要です。
4. `const firebaseConfig = { ... };` という部分が表示されます。`{` から `}` までをコピーします。
5. `firebase-config.js` をメモ帳などで開き、最後の行を次のように書きかえて保存します。

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "design-tree-xxxxx.firebaseapp.com",
  projectId: "design-tree-xxxxx",
  storageBucket: "design-tree-xxxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> `apiKey` は秘密の鍵ではありません（Firebase の仕組み上、公開されて大丈夫な値です）。
> データは次の手順 4 のルールで守られます。

## 4. データの保存場所（Firestore）を作り、ルールを設定する

1. 左のメニューで「構築」→「Firestore Database」→「データベースを作成」を押します。
2. 場所は `asia-northeast1`（東京）がおすすめです（あとから変更できません）。
3. 「本番環境モード」を選んで作成します。
4. できたら「ルール」タブを開き、中身をすべて消して、`firestore.rules` の中身を貼り付けます。
5. 「公開」を押します。

これで、**ログインした本人だけ**が自分のプロジェクトを読み書きできます。他の人のデータは見えません。

## 5. アプリを公開する（GitHub Pages）

1. <https://github.com/> で無料アカウントを作ります（持っていれば不要）。
2. 右上の「+」→「New repository」を押します。
   - 名前: 例 `design-tree`
   - 「Public」を選ぶ
   - 「Create repository」を押す
3. 「uploading an existing file」（または「Add file」→「Upload files」）を押します。
4. **このフォルダの中身をすべて**（`icons` フォルダも含めて）ドラッグ＆ドロップし、「Commit changes」を押します。
5. リポジトリの「Settings」→ 左の「Pages」を開きます。
   - 「Branch」を `main`、フォルダを `/ (root)` にして「Save」します。
6. 1〜3 分待つと、上に URL が表示されます（例: `https://あなたのユーザー名.github.io/design-tree/`）。

## 6. 公開した場所を Firebase に登録する

1. Firebase の「Authentication」→「設定」タブ →「承認済みドメイン」を開きます。
2. 「ドメインの追加」で `あなたのユーザー名.github.io` を追加します。

## 7. スマホに入れる

**iPhone**

1. Safari で手順 5 の URL を開きます。
2. 下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」を押します。

**Android**

1. Chrome で手順 5 の URL を開きます。
2. 右上の「⋮」→「アプリをインストール」（または「ホーム画面に追加」）を押します。

**PC** も Chrome や Edge で開けば、アドレスバーの右のボタンからインストールできます。

## 8. 使い方

1. アプリを開き、プロジェクト一覧の「ログイン」を押します。
2. 初めてのときは、メールアドレスとパスワード（6 文字以上）を入れて「新しく登録する」を押します。
3. 2 台目からは、同じメールアドレスとパスワードで「ログイン」を押します。
4. プロジェクト一覧の上に「**クラウドと同期済み**」と出ていれば同期できています。

覚えておくこと:

- **最初のログイン:** ログインする前にその端末で作ったプロジェクトは、最初にログインしたときにアカウントへ移ります。
- **電波がないとき:** 電波がなくても使えます。つながったときに同期されます。
- **ログアウト:** ログアウトすると、その端末からはプロジェクトが消えます（クラウドには残っています。もう一度ログインすると戻ります）。
- **パスワードを忘れたとき:** メールアドレスを入れて「パスワードを忘れた」を押すと、再設定のメールが届きます。

## アプリを新しい版に更新するとき

1. GitHub のリポジトリで「Add file」→「Upload files」を開きます。
2. 新しいフォルダの中身をドラッグします。
   **ただし `firebase-config.js` だけはアップロードしないでください**（あなたの設定が消えてしまいます）。
3. 「Commit changes」を押します。数分後、アプリを開き直すと新しい版になります。

## 料金について

Firebase の無料プラン（Spark プラン）で使えます。個人や少人数で使う程度なら、通常は無料の範囲に収まります。
支払い情報を登録しない限り、料金が発生することはありません。

## claude.ai 版との関係

claude.ai 版と独立アプリ版は、データの保存場所が別です。プロジェクトは自動では移りません。

## うまくいかないとき

| 表示 | 確認すること |
|---|---|
| 「メール/パスワードのログインが有効になっていません」 | 手順 2 |
| ログインできるが「同期できませんでした」 | 手順 4 のルールを「公開」したか |
| 「Firebase に接続できません」 | 手順 3 の設定の貼り付け（`{ }` や `"` が欠けていないか）、インターネット接続 |
| ログイン画面が出ない（「ログイン」ボタンがない） | `firebase-config.js` が `null` のままになっていないか |
